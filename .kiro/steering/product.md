# Product Overview

This is a collaborative whiteboard application that allows users to create and manage digital drawing boards. The application features:

## Core Features
- **User Authentication**: Google OAuth integration with JWT-based session management
- **Board Management**: Create, view, and delete drawing boards
- **Canvas Drawing**: Interactive drawing canvas using Fabric.js with various tools
- **User Dashboard**: Personal workspace to manage boards and user settings

## User Flow
1. Users sign up/login via Google OAuth or traditional email/password
2. Access personal dashboard to view existing boards
3. Create new boards or open existing ones
4. Use drawing tools on the canvas (powered by Fabric.js)
5. Boards are automatically saved and can be accessed later

## Target Users
- Individuals and teams needing collaborative drawing/whiteboarding tools
- Users who want a simple, web-based alternative to physical whiteboards
- Anyone requiring visual collaboration and idea sharing capabilities
